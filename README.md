# System Programming Learning Repository

## 🚀 Overview
This repository serves as a structured learning path for understanding system programming, diving deep into low-level programming concepts, operating system interactions, and computer systems architecture.

## 📚 Learning Objectives
- Master low-level memory management and allocation techniques
- Develop a deep understanding of process and thread lifecycle
- Learn system call interactions and kernel programming
- Build proficiency in systems-level programming languages (C, Rust)
- Understand computer systems architecture and performance optimization

## 🔍 Key Learning Areas

### 1. Memory Management
- Dynamic memory allocation strategies
- Pointer manipulation and memory safety
- Memory profiling and leak detection
- Stack vs. Heap memory understanding

### 2. Process and Thread Management
- Process creation and lifecycle
- Inter-Process Communication (IPC) mechanisms
- Thread synchronization techniques
- Concurrency patterns and challenges

### 3. System Calls and Kernel Interactions
- Understanding POSIX system calls
- File descriptor management
- Process scheduling
- Signal handling

### 4. Low-Level I/O Operations
- Buffered vs. Unbuffered I/O
- File system interactions
- Network socket programming
- Performance-critical I/O techniques

## 🛠 Technology Stack
- **Languages**: C, Rust
- **Tools**: 
  - GCC/Clang
  - Valgrind
  - GDB
  - Perf
- **Operating Systems**: Linux, macOS
